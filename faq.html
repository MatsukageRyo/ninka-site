FAQ

What is Kagi?

Kagi is a secure SSH terminal for iPhone. Kagiは、iPhoneからSSH接続してサーバーを操作するためのセキュアなターミナルアプリです。

Does Kagi collect data?

No. Kagi does not collect user data and does not include analytics, ads, or tracking. Kagiはユーザーデータを収集しません。

Where are credentials stored?

Passwords and private keys are stored in iOS Keychain. パスワードと秘密鍵はiOS Keychainに保存されます。

What does Kagi Pro unlock?

Kagi Pro unlocks multiple saved connections, multiple active sessions, Remote Document Viewer, and default tmux/Docker attach helpers. Kagi Proでは複数の保存済み接続、複数のアクティブセッション、Remote Document Viewer、tmux/Docker attachの標準ヘルパーが利用できます。

How cancel Kagi Pro?

Kagi Pro is managed through Apple ID subscriptions. You can cancel it from iOS Settings > Apple ID > Subscriptions. Kagi Proの解約はApple IDのサブスクリプション管理画面から行えます。

Can I use Kagi with any server?

Use Kagi only with servers you own or are authorized to access. Kagiは、所有している、またはアクセス許可を得ているサーバーにのみ使用してください。
