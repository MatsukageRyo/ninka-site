Accessibility

Kagi is a secure SSH terminal for iPhone. This page summarizes accessibility support and known limitations for Kagi users.

Current status

This page is informational and is not a claim that any App Store Accessibility Nutrition Label has already been verified. Final App Store accessibility responses will be based on real-device TestFlight QA.

Kagi is designed to work with iOS accessibility features where practical, including labelled app controls, system text settings, and standard iOS settings screens.

The terminal area displays remote shell output. Some command-line programs running on a server may not expose semantic information in the same way as native iOS controls.

Accessibility-related areas

  • iPhone app navigation, connection list, settings, support, privacy, and terms screens use native iOS-style controls where practical.
  • Kagi has no audio or video content in version 1.0, so captions and audio descriptions are not applicable.
  • Critical credentials are stored locally in iOS Keychain, and Kagi does not require account registration.

Known limitations

  • Terminal content depends on the remote server and the command-line application being used.
  • Some full-screen terminal programs may be difficult to use with assistive technologies because they are text-terminal applications rather than native iOS interfaces.
  • Color may be used for connection status, but Kagi also provides text labels and status context where possible.

Before App Store accessibility labels

Before any Accessibility Nutrition Label response is submitted in App Store Connect, Kagi should be checked on a real iPhone using the final TestFlight build for common tasks such as adding a connection, starting an SSH session, switching sessions, using Kagi Pro purchase and restore flows, opening settings, and reviewing support and legal links.
