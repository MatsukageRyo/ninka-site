Claude Codeの承認待ち、実はけっこうストレス。

  • Claude Codeを走らせて離席。
    戻ってみたら承認待ちで止まっていた。

  • iPhoneに通知は来ない。
    承認待ちに気づくのは、PCに戻ったとき。

  • PCに戻って「y」を打つだけで5分ロス。
    たった1文字のために作業が止まる。

Ninkaなら、iPhoneからワンタップ。
コードの流れを、止めない。

3ステップで、今日から使える。

むずかしい設定は不要。すぐに始められます。

1

Tailscaleを入れる

PCとiPhoneにTailscaleをインストール。ルーターの設定変更は不要です。

2

Ninkaで接続先を登録

TailscaleのIPアドレスを入力するだけ。SSH鍵にもパスワードにも対応。

3

tmuxセッションに接続

Claude Codeが動いているセッションを選んでタップ。あとは承認ボタンを待つだけ。

主な機能

シンプルだけど、必要なものは全部入り。

チャット風UI

ターミナル出力をLINEのようなチャットバブルで表示。サーバーの応答が見やすく、直感的に操作できます。

承認パターン自動検出

(y/n)、(Y/n)、(y/n/a)、Allow? などの承認プロンプトを自動で検出し、大きな承認ボタンを表示します。

ワンタップ操作

承認(y)、拒否(n)、すべて許可(a)、中断(Ctrl+C)をワンタップで送信。キーボード入力は不要です。

tmuxセッション対応

tmuxセッションの一覧表示・選択・自動アタッチに対応。デフォルトセッション設定で接続をさらに高速化。

対応するAIエージェント

特定のツールに依存しない、汎用的な仕組み。

Claude Code Aider Cursor Agent GitHub Copilot CLI Cline Roo Code
